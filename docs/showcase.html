Open-source learning project · engineering showcase

不止一个聊天框。
这是可观察、可约束的 Agent Runtime。

用 FastAPI、LangGraph、MCP 和 Vue 3 构建个人 Agent Runtime；重点验证流式任务、工具调用、人审、安全边界、状态持久化与评测闭环。

FastAPILangGraphMCPVue 3SQLite / PostgreSQLHITL
公开展示说明：GitHub Pages 仅托管这份静态作品集、架构图与学习内容；需要模型 Key、文件系统或命令执行的 Runtime 仅支持本地运行，不会暴露 API Key 或开放公共 Agent 接口。

执行不是黑盒

用户看到模型何时开始、选择了什么工具、何时需要确认，以及最终如何验证结果。

1. 创建任务分配 runId 与 traceId
2. 规划与调用工具工具参数经过 schema 校验
3. 人工确认高风险操作进入 HITL
4. 结果与验证保存事件并反馈前端
